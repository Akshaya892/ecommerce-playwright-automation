# E-commerce Playwright Automation

UI test automation project using **Playwright, TypeScript, Cucumber BDD, and Page Object Model (POM)**.

## Tech Stack

- Playwright
- TypeScript
- Cucumber.js
- Page Object Model (POM)
- Node.js

## Project Structure

```text
ecommerce-playwright-automation/
├── features/
├── pages/
├── step-definitions/
├── support/
├── test-data/
├── reports/
├── cucumber.js
├── package.json
└── tsconfig.json
```

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Akshaya892/ecommerce-playwright-automation.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ecommerce-playwright-automation
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Install Playwright Chromium:

   ```bash
   npx playwright install chromium
   ```

## Run Tests

```bash
npm test
```

## Generate HTML Report

The Cucumber HTML report is generated at:

```text
reports/cucumber-report.html
```
